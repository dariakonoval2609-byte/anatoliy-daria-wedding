# Весільний сайт і форма відповідей

Сайт не зберігає дані гостей у GitHub. Відповіді зберігаються в окремій вкладці Google-таблиці **«Відповіді гостей»** і прив’язуються до ПІБ та коду запрошення.

## Підключення Google-таблиці

1. Відкрийте потрібну таблицю й перейдіть до **Розширення → Apps Script**.
2. Скопіюйте в редактор вміст файлу `Code.gs` і збережіть проєкт.
3. Запустіть `setupWeddingRsvp()` один раз та підтвердьте запитані Google дозволи. Скрипт додасть у першу вкладку колонку **«Код запрошення»**, заповнить порожні коди та створить вкладку **«Відповіді гостей»**.
4. У Apps Script виберіть **Розгорнути → Нове розгортання → Вебзастосунок**. Виконання — від вашого облікового запису; доступ — для всіх, хто має посилання. Саму таблицю залиште з поточними обмеженнями доступу.
5. Скопіюйте URL розгортання, що закінчується на `/exec`, і вставте його в `RSVP_ENDPOINT` у `index.html`.
6. Опублікуйте сайт GitHub Pages і додайте кожному гостю персональне посилання з його кодом: `АДРЕСА_САЙТУ/?invite=КОД_ЗАПРОШЕННЯ`.

Вебзастосунок приймає відповіді лише коли код запрошення та ПІБ збігаються з рядком у першій вкладці. Повторна відповідь оновлює попередню для цього коду. Вкладка з відповідями містить час останнього оновлення.

**Не додавайте ПІБ, коди запрошень чи експорт таблиці до репозиторію GitHub.** Публічний сайт містить лише форму та адресу вебзастосунку; список гостей і коди залишаються у вашій Google-таблиці.
